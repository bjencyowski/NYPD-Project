Replacing Victim race outlier values with NA

# creating a string for races that don't match convention
# unknowns are changed to NA for uniformity across the data set
vic_race_filter <- c("UNKNOWN")

# replacing those "UNKNOWN"s with NA
nypd <- nypd |> 
    replace_with_na(replace = list(Vic_race = vic_race_filter))

Day of Week vs. Time Incident Frequency Heat Map

The heat map will show the frquency of the incidents based off the time it occured and the day of the week. The ‘Key’ variable is needed to ensure each incident only gets counted once, since some Keys are listed more than once if there were multiple victims

# creating a new df 'dow_heat' with the Key, Date, and Time.
# added a new column that contains the day of the week
dow_heat <- nypd |> 
    select(Key, Date, Time) |> 
    mutate(
        # using the weekdays function to find the day of the week
        Weekday = weekdays(Date),
        # days of the week are ordered as such for visual clarity in the heat map
        Weekday = factor(Weekday, levels = c("Monday", "Tuesday", "Wednesday", "Thursday",
                                             "Friday", "Saturday", "Sunday")),
        # extracting just the hour of each incident
        Hour = hour(Time),
    ) |>
    # counting each incident as once occurence instead of how many victims there were
    distinct(Key, Weekday, Hour, .keep_all = TRUE) |>
    count(Weekday, Hour, name = "Incidents")
# using geom_tile to create heat map of day of week vs time of shooting
ggplot(dow_heat, aes(x = Hour, y = fct_rev(Weekday), fill = Incidents)) +
    geom_tile(color = "white", lwd = 0.1, linetype = 1) +
    geom_text(aes(label = Incidents), color = "white", size = 3) +            
    scale_x_continuous(breaks = c(0, 4, 8, 12, 16, 20),
                     expand = c(0, 0)) +
    scale_y_discrete(expand = c(0,0)) +
    coord_fixed(ratio = 1) +
    labs(y = NULL, title = "Day of Week vs. Time Incident Frequency Heat Map") +
    theme(axis.text.y = element_text(vjust = 0.5),
          #axis.text.x = element_text(size = 12),
          panel.background = element_blank(),
          plot.background = element_blank(),
          plot.title = element_text(size = 18, hjust = 0.5),
          legend.position = "none")

Model Analysis

Incident Interval Distribution

Below I’ve calculated and plotted the time interval between each incident to determine what distribution (if any) this metric most closely follows.

Incident Interval Calculation

intervals <- nypd |> 
    select(Key, Date, Time) |> 
    mutate(date_time = ymd_hms(paste(Date, Time))) |>  
    distinct(Key, .keep_all = TRUE) |> 
    arrange(date_time) |>
    mutate(interval_hours = as.numeric(difftime(date_time, lag(date_time), units = "hours"))) |> 
    filter(!is.na(interval_hours)) |> 
    ungroup()

# calculating the mean and lambda interval
mean_int <- mean(intervals$interval_hours)
lambda_int <- 1 / mean_int

Incident Interval Model and Analysis

The intverals follow a Poisson/Exponential distribution. The histogram is plotted using density rather than raw count to ensure the y-axis scale will be the same between the histogram and the density curve. The vertical line shows the calculated interval mean, approximately 7.1 hours.

ggplot(intervals, aes(x = interval_hours)) +
    # using the proportion density rather than actual count to overlay exponential distribution curve
    geom_histogram(aes(y = after_stat(density)),
                       binwidth = 1,
                       fill = "#F8766D",
                       color = "white") +
    # exponential curve
    stat_function(fun = dexp,
                  args = list(rate = lambda_int),
                  color = "#00BFC4",
                  linewidth = 1) +
    # vertical line showing the calculate mean
    geom_vline(xintercept = mean_int,
               linetype = "dashed",
               color = "#00BA38",
               linewidth = 1.1) +
    labs(title = "Shooting Interval Density",
         subtitle = "Plot truncated to 48 hours for visual clarity",
         x = "Incident Interval in Hours",
         y = "Density") +
    theme(plot.title = element_text(size = 18, hjust = 0.5),
          plot.subtitle = element_text(hjust = 0.5),
          panel.background = element_blank(),
          plot.background = element_blank()) +
    # adjusting the shown x-axis for clarity
    coord_cartesian(xlim = c(0, 48))

Potential Bias

Reporting

This dataset only records incidents where someone was actually wounded or killed. It does not include incidents where people were shot at and not wounded. It may seem obvious when said aloud, but this data doesn’t include incidents that weren’t reported. There may have been incidents where someone was wounded but the police weren’t called.

Racial

New York is one of the most diverse cities in the world. From a data standpoint, it may make sense to group a victim’s race into a nice and neat category, but there may be victims who would potentially not identify with any of the given demographics, but were lumped into the closest fitting choice.
